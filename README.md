Project Overview
This is a 5-page website I built for Kevin's Cafe, a local coffee shop in Springs. Part 1 used pure HTML5 code with no CSS or JavaScript, as instructed. Part 2 adds full CSS styling, layout, and responsive design across all pages.

Website Goals and Objectives
- Establish an online presence for Kevin's Cafe so customers can find our menu, location, and contact details easily.
- Provide clear information about our products, prices, and branch locations.
- Allow customers to submit enquiries (catering, bookings) and general contact messages directly through the website.
- Build trust and credibility through customer testimonials and a professional, welcoming design.
- Ensure the site is fully usable on mobile devices, since many customers will browse on their phones.

Key Performance Indicators (KPIs):
- Number of enquiry/contact form submissions received.
- Website visits and time spent on the Menu page.
- Mobile vs desktop visitor ratio (site must perform well on both).

Key Features and Functionality
- 5-page responsive website: Home, About Us, Menu, Enquiries, Contact Us.
- Fully responsive design, adapting layout across desktop, tablet, and mobile screens (Part 2).
- Menu page with featured item cards and supporting item cards, including pricing.
- Customer testimonials section on the homepage.
- Working enquiry form (catering, bookings, general questions) and a separate contact form.
- Embedded Google Map showing our Strubenvale branch location.
- Consistent navigation menu across all pages.

Timeline and Milestones
- Part 1 (Planning & HTML Structure): Organisation research, project proposal, sitemap, file structure, and basic HTML pages completed and submitted.
- Part 2 (CSS Styling & Responsive Design): External stylesheet, typography, layout (Flexbox/Grid), decoration, pseudo-classes, and full responsive design completed and submitted.
- Part 3 (Functionality & SEO): JavaScript interactivity, form validation, SEO optimisation, and final deployment — upcoming.

Project Files
All the HTML files are sitting in the main project folder, images are saved inside an "images" subfolder, and the stylesheet is inside a "css" subfolder:

1. index.html - Home page with a short welcome message, main features, and customer testimonials.
2. about.html - Background info about the cafe, our mission, vision, and team details.
3. products.html - Menu page listing our coffee, baked goods, and breakfast meals with prices.
4. enquiry.html - Form page for customer questions, table reservations, or catering requests.
5. contact.html - Contact numbers, physical addresses, embedded Google Map, and message form.
6. README.md - Documentation and image sources.
7. images/ - Subfolder containing all JPEG pictures used on the site.
8. css/style.css - External stylesheet controlling all styling and responsive design across the site.

Page Details

 Home Page (index.html): Welcomes visitors to the site, gives a short overview of what we offer, shows a picture of the shop counter, includes customer testimonials, and has a link to the menu.

 About Us (about.html): Explains how the cafe started in Springs, our daily goals, and who works behind the counter.

 Menu (products.html): Lists our items under Hot Drinks, Bakery, and Breakfast Combos, along with item pictures and prices, styled with featured and supporting item cards.

 Enquiries (enquiry.html): Has a working HTML form with text inputs, a dropdown menu, and submit/reset buttons.

 Contact Us (contact.html): Lists our direct phone number, email address, physical location in Strubenvale, a second branch address, a Google Map iframe, and a direct contact form.

Project Overview
This is a basic 5-page HTML website I built for Kevin's Cafe, which is a local coffee shop in Springs. Since this is Part 1 of the assignment, I only used pure HTML5 code. I didn't add any CSS or JavaScript, as instructed in the assignment guidelines.

Project Files
All the HTML files are sitting in the main project folder, and all the images are saved inside an "images" subfolder:

1. index.html - Home page with a short welcome message and main features.
2. about.html - Background info about the cafe, our mission, vision, and team details.
3. products.html - Menu page listing our coffee, baked goods, and breakfast meals with prices.
4. enquiry.html - Form page for customer questions, table reservations, or catering requests.
5. contact.html - Contact numbers, physical addresses, embedded Google Map, and message form.
6. README.md - Documentation and image sources.
7. images/ - Subfolder containing all 6 JPEG pictures used on the site.

Page Details

 Home Page (index.html): Welcomes visitors to the site, gives a short overview of what we offer, shows a picture of the shop counter, and has a link to the menu.

 About Us (about.html): Explains how the cafe started in Springs, our daily goals, and who works behind the counter.

 Menu (products.html): Lists our items under Hot Drinks, Bakery, and Breakfast Combos, along with item pictures and prices.

 Enquiries (enquiry.html): Has a working HTML form with text inputs, a dropdown menu, and submit/reset buttons.
 Contact Us (contact.html): Lists our direct phone number, email address, physical location in Strubenvale, a second branch address, a Google Map iframe, and a direct contact form.
